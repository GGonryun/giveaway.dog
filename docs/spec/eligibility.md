# Eligibility

Which participants of a giveaway can win. The host sets the criteria in the giveaway editor.

- `ELIG-001` A participant below the minimum quality score is not eligible.
- `ELIG-002` A participant below the minimum number of completed tasks is not eligible.
- `ELIG-003` A participant who came from a source outside the allowed external platforms is not eligible.
- `ELIG-004` Relaxing a criterion never makes an eligible participant ineligible.
- `ELIG-005` A participant who meets every criterion is eligible.
